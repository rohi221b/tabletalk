# TableTalk

An AI-powered café companion that helps customers at the same physical café discover other customers who are voluntarily open to meeting someone new.

## Language

**Café Session**:
A scoping container that groups all Participants physically present at one café. Created once per café; identified by a permanent QR code. Expiry is handled at the Participant level, not the Session level.
_Avoid_: Room, lobby, channel, event

**Participant**:
A person who has joined a Café Session and created a Temporary Profile. A Participant is not necessarily discoverable; they must also opt in via the Availability toggle.
_Avoid_: User (too generic outside this context), customer, visitor

**Temporary Profile**:
The profile data a Participant creates within a Café Session: first name or nickname, short intro, selected interests, social intention, preferred interaction format, and availability duration. Expires automatically; never persists across sessions.
_Avoid_: Account, user profile

**Discoverability**:
The explicit opt-in state that makes a Participant visible to the matching system. A Participant sets Discoverability by activating the Availability toggle on Screen 4. A Participant who has not set Discoverability cannot be surfaced as a Match Suggestion to anyone.
_Avoid_: Visibility, active, online

**Conversation Request**:
A directional invitation sent by one Participant to another after browsing the Discover list. The recipient accepts or declines. A Connection is formed only after both parties have accepted each other's intent. The sender's name is not revealed until Connection.
_Avoid_: Match request, friend request, ping

**Connection**:
The state reached when both Participants have accepted a Conversation Request from one another. Only at this point are first names and profile details revealed. The system generates one Icebreaker upon Connection. A Connection can optionally become an Open Table.
_Avoid_: Match (overloaded), friendship, link

**Open Table**:
An optional state a Connection can enter after forming. When two connected Participants open their table, other Participants in the same Café Session can see it in the browse list and send a Join Request. A table is closed by default.
_Avoid_: Group, room, chat

**Join Request**:
A request sent by a Participant to join an Open Table. All current members of the table must unanimously accept before the requesting Participant joins. If any member declines, the request is silently dismissed.
_Avoid_: Group invite, join link

**Icebreaker**:
A single, personalised conversation starter generated by Gemini after a Connection is established. Based on the shared interests and intentions of both Participants. Intended to be used in person, not via the app.
_Avoid_: Opener, intro, conversation prompt

**Interest**:
A topic tag selected by a Participant from a fixed taxonomy of ~20 options (e.g. technology, travel, entrepreneurship, music). Interests are the primary signal for matching. No free-text interests; the fixed list ensures set-intersection matching is reliable.
_Avoid_: Tag, hobby, topic

**Intention**:
The social goal a Participant declares when creating their Temporary Profile. One of four options: make friends, professional networking, discuss interesting topics, find an activity partner. Used as a tie-breaker in matching; two Participants with the same Intention rank higher than those with different ones.
_Avoid_: Goal, purpose, mode

**Availability Window**:
The duration a Participant declares they are open to meeting someone: 15, 30, or 60 minutes. When the window expires, Discoverability is automatically set to off (soft pause). The Participant can extend without re-onboarding.
_Avoid_: Availability time, session time, timer

**Session ID**:
The unique identifier for a Café Session, derived as `{cafeId}_{YYYY-MM-DD}`. The QR code encodes only the `cafeId`; the backend resolves to the current day's Session ID. Ensures Participants from different days are never matched.
_Avoid_: Room ID, session token
